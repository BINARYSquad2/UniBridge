# Обновление навигации и каталога

## Что изменилось
- Верхняя кнопка «Менторы» снова ведёт к прежнему блоку «Популярные менторы» на главной странице (/#mentors).
- «Смотреть всех менторов» открывает полный каталог /mentorslist для учеников.
- После входа обе роли попадают в кабинет /profile.
- Слева в кабинете ментора появилась кнопка «Запросы» — переход на /requests.
- Заявки учеников и каталог менторов оформлены карточками в стиле блока «Популярные менторы», на всю область страницы справа от меню.
- На небольшом экране боковое меню размещается сверху, карточки идут в одну колонку.
- Ученики отправляют сообщение выбранному ментору и видят статус в «Моих заявках».
- Ментор видит только свои заявки, может принять или отклонить их.
- Существующий ученический кабинет и главная страница сохранены. Демо-статистика и примерные карточки на главной остаются демонстрационными; полный каталог использует зарегистрированных менторов из базы.

## Установка
Скопируйте содержимое папки UniBridge поверх своего проекта, сохранив backend/.env.
Архив не включает node_modules, .git и секреты из .env.

Терминал 1, из папки проекта:
npm install
npm run dev

Терминал 2:
cd backend
go run ./cmd/server

PostgreSQL должен быть запущен. Сервер автоматически применяет миграции 000004 и 000005.
Если используете собранный Go-сервер, пересоберите его: SQL-миграции встроены в бинарный файл.

## Проверка
1. Зарегистрируйте ментора с описанием и направлениями. В кабинете слева откройте «Запросы».
2. Выйдите, зарегистрируйте ученика. Нажмите верхнюю кнопку «Менторы»: откроется старый блок на главной.
3. Нажмите «Смотреть всех менторов», затем «Подать заявку» на карточке реального ментора.
4. Войдите этим ментором, откройте «Запросы». Там должна появиться карточка ученика.
5. Примите или отклоните заявку и проверьте статус в аккаунте ученика.

Подбор сортирует менторов по общим направлениям. Старые менторы без направлений показываются без совпадений.
Один ученик может иметь только одну принятую заявку, согласно ограничению базы.
TypeScript проверен. Полная Vite-сборка и Go/PostgreSQL в среде подготовки не запускались.
